## 🚀 How to Run Locally

You can run this project instantly using any of the following methods:

### Option 1: Direct File Open
Double click on `index.html` in your file explorer to open it directly in Chrome, Edge, Safari, or Firefox.

### Option 2: Python HTTP Server
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.

### Option 3: Node / npx serve
```bash
npx serve .
```
